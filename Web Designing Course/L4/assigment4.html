Assignment 4: Web Development & Web Designing

Introduction to Web Development

Web development means creating websites using HTML, CSS, and JavaScript.

Introduction to Web Designing

Web designing means making the website beautiful, user-friendly, and easy to use.

Why Learn HTML?

HTML is the backbone of every website. Without HTML, no webpage can be created.

Basic HTML Structure

Every HTML file starts with <html>, <head>, and <body> tags.

Assignment Objective

You will practice headings, lists, and tables using real web development content.

Description List (Terms + Definition)

Front-End
Everything the user sees (HTML, CSS, JS).
Back-End
Server-side logic, database, API.
Full-Stack Developer
A developer who knows both front-end and back-end.
