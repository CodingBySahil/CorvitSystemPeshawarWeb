## 🚀 Why This Repository Exists

This repository is your **digital notebook**.  
Everything taught in class will be available here so that you can:

- Revise lectures anytime  
- Practice code after class  
- Improve your logic and problem-solving skills  
- Build confidence in HTML, CSS, and JavaScript  

---

## 🧠 What You Will Learn in This Course

### 🔹 Month 1 – Web Designing (HTML, CSS, JavaScript)

By the end of the first month, you will be able to:

- Create complete webpages using **HTML**
- Design beautiful layouts using **CSS**
- Make websites interactive using **JavaScript**
- Understand how real websites work
- Build small but meaningful projects

You will practice:
- Forms, tables, images, and layouts  
- Responsive designs for mobile and desktop  
- JavaScript logic, conditions, functions, and DOM manipulation  
- Mini projects like **Calculator, To-Do App, Image Slider**, etc.

---

## 🧑‍💻 How to Learn Effectively from This Repo

To get the best results:

- Open the lecture after every class  
- Run the code on your own system  
- Change values and experiment  
- Break the code and fix it again  
- Ask questions — learning starts with confusion  

---

## ⚠️ Rules for Success

- Practice daily (even 30 minutes matters)
- Do not memorize code — **understand it**
- Write code with your own hands
- Make mistakes and learn from them
- Consistency is more important than speed
